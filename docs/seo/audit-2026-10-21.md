## Corrected production behavior

- Homepage and public page robots directives are indexable. The canonical, Open Graph, sharing-image and structured-data URLs consistently use `https://blitzstudio.xyz`.
- `robots.txt` advertises the populated 19-URL production sitemap.
- All canonical pages return HTTP 200 directly. HTTPS apex normalization, index aliases, extensionless aliases and the legacy `/contact` path use permanent 308 redirects.
- The previously failing www host reaches the same worker through a specific route, with no DNS record deletion, then redirects to the apex.
- Unknown URLs return real 404, with a noindex response directive.
- Seven regression tests cover production/preview configuration, forbidden staging fallback, preview noindex, redirects, canonical asset responses and 404 behavior. Cloudflare runs them and the site/SEO verifiers before deploying.
- Removed an obsolete hero-video poster preload after the switch to project images.

## Indexing scope

All 22 pages were crawled. Cookie Settings and the anonymous Creator management and Confidential finance previews retain intentional noindex directives and are omitted from the public sitemap. The remaining 19 pages passed the scoring runs above.

## Limits and follow-up

Search Console domain verification is prepared in the owner's signed-in browser. Adding its DNS proof and submitting the sitemap awaits explicit owner approval; neither is claimed complete. The sitemap is already publicly discoverable through robots.txt.

These are automated SEO and Best Practices scores. They do not guarantee search rankings or establish field Core Web Vitals; Google still needs to crawl and process the corrected signals.

The existing design fingerprint check detects the previously unreviewed hero/social changes and updated SEO generator. Its baseline was preserved; it was not refreshed to make a check pass. This release changes routing, metadata and validation rather than redesigning the page.
